🛒 Blinkit Sales Analysis Dashboard

📘 Project Overview

The Blinkit Sales Analysis Dashboard is an interactive Power BI project designed to analyze sales performance across various item types, outlet categories, and establishment years.
This dashboard provides valuable insights into total sales, product trends, and outlet contributions to help understand the business performance of Blinkit.

🧰 Tools & Technologies Used

Power BI – Data visualization & dashboard creation

Power Query – Data transformation and cleaning

Excel / CSV – Dataset preparation and import

DAX (Data Analysis Expressions) – Calculations and measures for KPIs

🔍 Key Insights

🥦 Fruits and Vegetables generated the highest sales among all categories.

🏬 Supermarket Type 1 contributed the largest share of total sales.

📅 Outlet establishment year 2018 showed a notable sales peak.

🍞 Low Fat items performed better than Regular Fat items in total sales.

📈 Balanced mix of Tier 1, Tier 2, and Tier 3 outlets shows wide market distribution.

KPI Cards: Total Sales, Average Rating, Item Weight, Number of Outlets

Bar Chart: Sales by Item Type

Line Chart: Sales by Outlet Establishment Year

Donut Chart: Sales by Outlet Type

Column Chart: Sales by Item Fat Content

Filters: Item Type, Outlet Type, Outlet Tier
